1. Codons: The Language of Life

Understanding Genetic Code

DNA stores genetic information using just four chemical bases: Adenine (A), Thymine (T), Guanine (G), and Cytosine (C). These bases are read in groups of three, called codons, which specify which amino acid should be added during protein synthesis.

Combinatorial Mathematics of Codons:

  • With 4 bases and codon length of 3: 4³ = 64 possible codons
  • These 64 codons encode only 20 amino acids (plus start/stop signals)
  • This redundancy provides error tolerance—multiple codons can code for the same amino acid
  • General formula: With n bases and codon length k, there are nk possible codons

Special Codons:

  • START Codons (green): ATG (primary), GTG, TTG, CTG—signal where protein synthesis begins
  • STOP Codons (red): TGA, TAG, TAA—signal termination of protein synthesis
  • Regular Codons: All others code for specific amino acids

The genetic code is nearly universal across all life forms, suggesting it evolved early in the history of life. In RNA (used during protein synthesis), Thymine (T) is replaced by Uracil (U).

Key Concept: Permutations count arrangements where order matters, while combinations count selections where order doesn't matter. For codons, order is critical—ATG ≠ GTA!

2. De Bruijn Sequences: Maximum Information Density

The Shortest Superstring Problem

A De Bruijn sequence is a cyclic sequence that contains every possible n-letter word exactly once as a substring. This elegant mathematical construct has surprising connections to genetics and information theory.

Why This Matters for Genetics:

  • Information Density: DNA must pack maximum information into minimal space
  • Error Detection: Non-repeating patterns help identify where reading frames begin
  • Gene Finding: Algorithms search for patterns in genomic sequences to locate genes
  • Overlapping Genes: Some organisms use overlapping reading frames, similar to how De Bruijn sequences overlap substrings

Mathematical Properties:

  • For alphabet size k and substring length n: Total substrings = kn
  • Minimum sequence length = kn + n - 1
  • Example: Binary 3-tuples → 2³ = 8 substrings, minimum length = 8 + 3 - 1 = 10
  • The sequence is "cyclic"—the end wraps around to connect with the beginning

De Bruijn sequences were named after Dutch mathematician Nicolaas Govert de Bruijn (1918-2012), though they were independently discovered several times. They have applications in genome sequencing, cryptography, and even magic tricks!

Connection to DNA: While real DNA doesn't follow De Bruijn patterns exactly, understanding maximum information density helps us appreciate how evolution has optimized genetic code for compactness and error resistance.

3. Mutations, Checksums, and Error Detection

What is a Checksum?

A checksum is a small piece of data derived from a larger block of data, used to detect errors that may have been introduced during transmission or storage. The most familiar example is the ISBN (International Standard Book Number) on books.

DNA Checksums: A Simplified Model

This tool uses a simplified checksum model for educational purposes. Real genetic error detection is far more sophisticated:

  • Our Model: Digital root checksum (A=1, T=2, G=3, C=4, sum digits until single digit)
  • Reality: DNA has multiple error-checking mechanisms:
    • Proofreading enzymes during replication (error rate ~1 in 10⁷)
    • Mismatch repair systems fix errors after replication (~1 in 10⁹ after repair)
    • Codon redundancy (wobble base pairing)—many mutations don't change amino acids
    • DNA repair pathways fix damaged DNA from radiation, chemicals, etc.

Types of Mutations:

  • Point mutations: Single base changes (what we simulate below)
  • Silent mutations: Change codon but not amino acid (due to redundancy)
  • Missense mutations: Change amino acid in protein
  • Nonsense mutations: Create premature stop codon
  • Insertions/Deletions: Shift reading frame (frameshift mutations)

Mutation Rates in Nature: Human germline mutation rate is approximately 1.2 × 10⁻⁸ per base per generation, meaning each person is born with about 60-100 new mutations compared to their parents.

Educational Note: This checksum is a toy model to illustrate the concept of error detection. Real biological systems use redundancy, enzymatic proofreading, and repair mechanisms far more sophisticated than simple checksums. However, the principle—that errors can be detected by comparing computed values—remains the same.

4. Genetic Algorithms: Evolution as Computation

Mimicking Natural Selection

Genetic algorithms (GAs) are optimization techniques inspired by Darwin's theory of evolution. They use concepts of selection, crossover (recombination), and mutation to evolve solutions to complex problems.

How Genetic Algorithms Work:

  1. Initialization: Create random population of candidate solutions
  2. Evaluation: Measure "fitness" of each solution
  3. Selection: Choose fitter individuals to "reproduce"
  4. Crossover: Combine pairs of solutions to create offspring
  5. Mutation: Randomly modify some solutions
  6. Replacement: Form new generation and repeat

The Traveling Salesman Problem (TSP):

Given a set of cities and distances between them, find the shortest route that visits each city exactly once and returns to the start. This is an NP-hard problem—testing all routes becomes impossible even for moderate numbers of cities:

  • 10 cities: 181,440 routes
  • 20 cities: 6.08 × 10¹⁶ routes (would take >1 million years to check all)
  • 30 cities: 4.42 × 10²⁹ routes (longer than age of universe!)

Crossover Methods for TSP:

Simple crossover doesn't work for TSP because cities can't repeat. Special methods preserve valid tours:

  • PMX (Partially Mapped Crossover): Maps positions between parents, preserving relative order
  • OX (Order Crossover): Takes segment from one parent, fills remaining from other in order
  • CX (Cycle Crossover): Each city maintains position from at least one parent

Connection to Real Genetics:

  • Population: Like organisms in an ecosystem
  • Fitness: Analogous to reproductive success
  • Crossover: Sexual reproduction mixing parental genes
  • Mutation: Random copying errors during reproduction
  • Selection: "Survival of the fittest"

Applications Beyond TSP: Genetic algorithms are used in circuit design, scheduling, machine learning, drug design, and even evolved antenna designs for NASA spacecraft!

Key Insight: GAs don't guarantee finding the absolute best solution, but they often find very good solutions in reasonable time for problems where testing all possibilities is impossible. This mirrors evolution—organisms aren't "perfect," but they're well-adapted to their environments.
